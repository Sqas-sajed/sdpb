# Implementation-Oriented Analysis: Sinha-Zahed & Caron-Huot Papers vs. Current Code

## EXECUTIVE SUMMARY

The current `eft_bounds/crossing_pipeline.py` correctly implements the core mathematical transformations from both papers but has several inconsistencies in terminology, variable naming, and the relationship between dispersion-relation sum rules and SDPB dual formulation.

---

## 1. SINHA-ZAHED (2021) KEY EQUATIONS

### Eq. (3) - Crossing-Symmetric Basis
**Paper notation:**
```
M₀(s₁, s₂) = Σ_{p,q≥0} W_{p,q} x^p y^q
where:
  x = -(s₁s₂ + s₂s₃ + s₃s₁)
  y = -s₁s₂s₃
  s₁ = s - μ/3, s₂ = t - μ/3, s₃ = u - μ/3
  μ = 4m²
```

**Current code:** ✓ CORRECT
- `x_polynomial()` and `y_polynomial()` correctly implement these with μ = 4m²
- Uses (s,t) basis with u = 4m² - s - t
- `expand_crossing_monomial()` expands x^p y^q to s,t monomials

### Eq. (4) - Dispersion Relation Inversion
**Paper notation:**
```
W_{n-m,m} = ∫_{2μ/3}^∞ (ds₁/s₁) Φ(s₁) Σ_{ℓ=0}^∞ (2ℓ + 2α) aℓ(s₁) B_{n,m}^{(ℓ)}(s₁)
```

**Key objects:**
- `B_{n,m}^{(ℓ)}(s₁)`: **Conversion kernels** from partial waves aℓ(s₁) to Wilson coefficients
- `aℓ(s₁)`: Partial wave coefficients (0 ≤ aℓ ≤ 1 by unitarity)
- `Φ(s₁)`: Prefactor involving Gegenbauer normalization
- α = (d-3)/2 for spacetime dimension d

**Current code:** ⚠️ **MISSING**
- No implementation of B_{n,m}^{(ℓ)}(s₁) kernels
- No direct computation from partial waves to W_{pq}
- Relies on indirect dual formulation instead

### Eq. (11) - Null Constraints
**Paper notation:**
```
∫_{δ₀}^∞ (ds₁/s₁^{α+1/2}) Σ_{ℓ=2}^∞ (2ℓ + 2α) aℓ(s₁) [C_ℓ^{(α)}(1)/π] D_{ℓ,α}^{(n,m)} / s₁^{2n+m} = 0

for m > n ≥ 1, where:

D_{ℓ,α}^{(n,m)} = Σ_{j=0}^m (-1)^{j+m} (-ℓ/2)_j (α+ℓ/2)_j (α+1/2)_j × 
                   (3j - m - 2n)Γ(m-n) / [j!(m-j)!(j-n)!] × (-4)^j
```

**Physical meaning:**
- For m > n, the coefficient W_{n-m,m} should vanish (it's outside the basis)
- This generates exact linear constraints on partial waves
- In EFT context: relates lower-order to higher-order Wilson coefficients

**Current code:** ⚠️ **INCONSISTENT**
- `derive_null_constraints()` in crossing_pipeline.py: Uses algebraic nullspace (CORRECT for full crossing)
- `get_null_constraints()` in null_constraints.py: Uses s↔u symmetry only (INCOMPLETE)
- Neither computes D_{ℓ,α}^{(n,m)} coefficients explicitly
- The D objects are fundamental for optimal dual functionals but not implemented

## 2. CARON-HUOT & DUONG (2021) KEY EQUATIONS

### Eq. (2.3) - Extremal EFT Basis
**Paper notation:**
```
M_low(s,t) = g²[1/s + 1/t + 1/u] - λ
             + g₂(s² + t² + u²) + g₃(stu) 
             + g₄(s² + t² + u²)² + g₅(s² + t² + u²)(stu)
             + g₆(s² + t² + u²)³ + g₆'(stu)² + g₇(s² + t² + u²)²(stu) + ...

where: E₂ = s² + t² + u², E₃ = stu
```

**Key insight:** The ring of symmetric polynomials is freely generated by E₂ and E₃

**Current code:** ✓ CORRECT
- `e2_polynomial()` and `e3_polynomial()` implement E₂, E₃
- `expand_extremal_monomial()` expands E₂^r E₃^q
- `extremal_label()` generates labels like "g2", "g3", etc.
- **BUT:** Uses m² = 0 for massless case (consistent with paper)
- **INCONSISTENCY:** crossing basis uses m² = 1, extremal uses m² = 0

### Eq. (2.17) - B_k Sum Rules
**Paper notation:**
```
B_k(t) = ∮ (ds/2πi) (1/s) [M(s,t)/[s(s+t)]^{k/2-1}]

Physical interpretation:
B_k(t) = Res_{s=0} [(2s+t)/(s(s+t)) × M(s,t)/[s(s+t)]^{k/2}]
       = <average of 1/m^k over high-energy spectral density>
```

**Current code:** ⚠️ **NOT EXPLICITLY IMPLEMENTED**
- No `compute_Bk_sum_rule()` function
- The connection to actual dispersion integrals is implicit
- PMP generator creates dual problem but doesn't label it as "B_k formulation"

### Eq. (2.22) - Sum Rule Expressions
**Paper notation:**
```
g₂ = <1/m⁴>
g₃ = <(3 - 4J²/(d-2))/m⁶>
g₄ = <(1 + 4-5d)/(2d(d-2))J² + 1/(d(d-2))J⁴)/m⁸>
```
where J² = J(J+d-3) is spin Casimir

**Current code:** ⚠️ **PARTIAL**
- `build_positivity_polynomials()` in physics.py computes spectral functions
- But not labeled as "B_k sum rules"
- Missing explicit J-dependent coefficients for general k

### Eq. (2.23) - Null Constraint Example
**Paper notation:**
```
0 = <n₄(m², J)>  where n₄(m², J) = [J²(2J² - 5d + 4)]/m⁸
```

**Physical meaning:** Balance spin-2 against higher spins

**Current code:** ✓ IMPLICIT
- Generated via nullspace of crossing symmetry
- Not explicitly constructed from J-dependent form

### Section 3 - SDPB Dual Formulation
**Paper approach:**
1. Start with B_k sum rules expressing g_k as averages
2. Add null constraints <n_k> = 0
3. Form linear combinations α₂<1/m⁴> + α₃<.../m⁶> + α₄<n₄> ≥ 0
4. Optimize coefficients α_i to maximize/minimize target ratio

**Current code:** ✓ CORRECT (but naming mismatch)
- `generate_pmp_for_linear_functional_bound()` implements this
- Uses null constraints correctly
- Dual problem structure matches paper
- **ISSUE:** Doesn't explicitly reference "B_k framework"

## 3. CRITICAL INCONSISTENCIES

### A. Variable Naming
**Should be:**
- W_{p,q} for crossing-symmetric coefficients (Sinha-Zahed eq. 3)
- g_k for extremal-EFT coefficients (Caron-Huot eq. 2.3)
- B_{n,m}^{(ℓ)} for dispersion kernels (Sinha-Zahed eq. 4)
- D_{ℓ,α}^{(n,m)} for null constraint kernels (Sinha-Zahed eq. 11)

**Current code uses:**
- Sometimes "Wilson coefficients" (ambiguous)
- Sometimes "symmetric basis coefficients" (unclear which one)
- No explicit B or D objects

### B. Mass Conventions
**Inconsistency:**
- Crossing basis (W_{pq}): uses m² = 1 (massive scalars, s_i = s - μ/3)
- Extremal basis (g_k): uses m² = 0 (massless scalars, s² + t² + u²)

**Papers:**
- Sinha-Zahed: massive case, μ = 4m²
- Caron-Huot: massless limit (though mentions massive generalizes)

**Fix needed:** Document which scenarios use which convention

### C. Null Constraints - Two Methods
**Method 1:** Algebraic nullspace of crossing map (current derive_null_constraints)
- ✓ Exact for full S₃ crossing symmetry
- ✓ Works in ordinary (s,t) or crossing (x,y) basis
- ⚠️ Doesn't show dispersion-theoretic origin

**Method 2:** Dispersion relation vanishing conditions (Sinha-Zahed eq. 11)
- Shows physical meaning (certain W_{n-m,m} must vanish for m>n)
- Gives D_{ℓ,α}^{(n,m)} coefficients useful for optimal functionals
- ⚠️ Not implemented

**Recommendation:** Keep both, clarify they're equivalent

### D. B_k Sum Rules Not Explicit
**Missing:**
- Function `compute_Bk_sum_rule(k, wilson_coeffs, mass_scale)`
- Explicit formulas for <1/m^k> averages
- Documentation mapping g_k = B_k evaluated

**Current workaround:** SDPB dual optimization implicitly uses these

## 8. EXISTING ASSUMPTIONS TO FIX

### Assumption 1: "Wilson coefficients are all independent"
**Reality:** Null constraints eliminate ~30% of coefficients

**Fix:** Always report (free_indices, substitution_rules) from eliminate_variables()

### Assumption 2: "Crossing pipeline only for full S₃ symmetry"
**Reality:** Papers use different levels:
- Sinha-Zahed: Full 3-channel crossing (s↔t↔u)
- Caron-Huot: Mainly s↔u with s=-t symmetry

**Fix:** Add parameter `crossing_symmetry_level = "su" | "stu" | "full_S3"`

### Assumption 3: "SDPB dual problem is independent of dispersion theory"
**Reality:** Optimal functionals are specific linear combinations of B_k sum rules

**Fix:** Output which B_k contribute to each bound

### Assumption 4: "Extremal basis = unique natural choice"
**Reality:** 
- Extremal (E₂, E₃) good for massless EFT
- Crossing (x, y) good for massive + crossing symmetry
- Related but distinct

**Fix:** Support both, clarify when each is preferred

### Assumption 5: "Null constraints from algebraic nullspace only"
**Reality:** Two derivations (algebraic & dispersion) should match

**Fix:** Implement both, add test comparing them
